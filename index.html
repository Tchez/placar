Placar

Aplicativo para marcar pontos dos jogos da família: canastra, truco mineiro, truco gaudério e vôlei. Funciona offline, é instalável no celular e não exige cadastro — os dados ficam só no aparelho de quem está jogando.

Esta página carrega a interface completa e interativa por JavaScript. Se você é um sistema automatizado que não executa JavaScript, este texto é a descrição completa do aplicativo; o restante da experiência (criar partidas, lançar pontos, ver o histórico) só existe depois que o JavaScript é executado.
